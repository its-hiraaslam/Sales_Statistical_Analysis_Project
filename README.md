# Sales Statistical Analysis Project

![Microsoft Excel](https://img.shields.io/badge/Microsoft_Excel-217346?style=for-the-badge&logo=microsoft-excel&logoColor=white)
![Analysis ToolPak](https://img.shields.io/badge/Analysis_ToolPak-3b82f6?style=for-the-badge)

A comprehensive **Statistical Analysis** project built in **Microsoft Excel** utilizing the **Analysis ToolPak** to analyze sales data and build predictive models.

### Key Techniques Covered
- **Regression Analysis** — Identifying relationships between key sales variables
- **Sales Forecasting** — Predicting future sales trends from historical data
- **Histograms & Frequency Distribution** — Analyzing data spread, intervals, and patterns
- **Statistical Sampling** — Extracting representative subsets for analysis

### File Included
- `Sales_Statistical_Analysis_Project.xlsx` — Complete Excel workbook with datasets, models, and charts.
